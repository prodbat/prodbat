Checking a delivery

Each POST has a Prodbat-Signature header like t=1767225600,v1=5f2b…. Compute the HMAC-SHA256 of the time, a full stop and the raw body (t + "." + body) with this secret, compare it with v1, and refuse it if the time is more than five minutes old. Use Prodbat-Delivery to drop repeats. The guide for coding agents has code for Node and Python.
